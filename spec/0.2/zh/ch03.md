## 3 词法

### 3.1 字符

- 正式记号都由 ASCII 字符组成。
- 非 ASCII 字符只出现在字符串（包括加引号的名字）、自由文本、注释和代称里，以及不加引号的角色名和参数名里。在自由文本和注释以外，不加引号的非 ASCII 词只出现在 `@` 后面和括号里：`@` 后面的应是声明过的代称；括号里的是代称，或角色名、参数名本身（3.6、16.5）。
- **编码。** 宿主适配器按宿主的规则解码，RNL 处理的是字符。写 RNL 的工具不应改变宿主文件的编码和换行符，不应加字节顺序标记（BOM）；不应写出宿主编码表示不了的字符，改为给警告。新文件建议用 UTF-8。
- **宿主注释里的非 ASCII 字符。** 适配器应写明哪些宿主验证过注释里的非 ASCII 字符；在别的宿主上，非 ASCII 字符给提示。

  注：各宿主的支持不一。ngspice（v42 起）、WRspice（标题除外）、Xyce 和新版 LTspice 接受注释里的非 ASCII 字符；HSPICE、PSpice、Eldo 的文档没写；Spectre 的手册说网表是 ASCII 文件；QSPICE 用 Windows-1252。不加 BOM 还有一个原因：旧版 ngspice 会把它粘到被 include 文件的第一个记号上，WRspice 在第 1 行以它开头时中止读入。

### 3.2 正式记号

| 记号 | 写法 |
|---|---|
| 关键字 | `@` 加大写的名字，如 `@PLACE`；或声明过的代称（16.5） |
| 引用 | 前缀加名字，可带端子和子对象，如 `#M1`、`#M1:d`、`%dp1::in_p`（第 6 章）。宿主名字或端子名后面可以紧跟下标，如 `&D<3>`、`&D<7:0>`（6.11） |
| 点 | `(x, y)`，不紧贴关键字或对象：前面是空白、注释、`{`、`;`、`=>` 或 `=`（3.8） |
| 括号 | 参数和角色的 `(` `)`，紧贴关键字或对象（3.5） |
| 花括号 | 集合的 `{` `}` |
| 分隔符 | `;`（分开成员）、`=>`（管道和命名）、`=`（成员开头的命名） |

括号内（参数、角色和点的 `()`，数组的 `[]`）另有字符串、数、`,`、`=`、`_` 和名字（参数名、角色名、`true`、`false`），在普通定义的体里还有参数空位 `?name`（6.10）。下标的 `<>` 和 `[]` 里只有不带符号的整数、`,` 和 `:`（6.11）。

### 3.3 自由文本

- 括号外，除了下面列出的字符，任何字符都可以作自由文本，包括全部非 ASCII 字符（如中文标点 `：`、`、`、`；`、`（`、`）`）和 `-`、`:`、`'`、`!`、`+`、`/`、`*`、`|`。例外是：
  - `@`、`#`、`&`、`%`、`$`、`?`、`"`、`;`、`=`、`{`、`}`、`(`、`)`：在括号外，它们开始正式记号或属于正式记号（3.2）。`?` 开始空位（6.10）；在符号体里，单独的 `?` 指用这个符号画出的对象（13.3）；
  - `[`、`]`、`<`、`>`：数组和下标的括号（3.7、6.11）；
  - `/*`：开始注释（3.4）。
- 几条位置规则让含义唯一：
  - 紧贴引用、后面是名字或引号的 `:` 或 `::`，照常是端子或子对象（6.4、6.5）。后面不是名字时，`:` 是自由文本，如 `Input pair: %dp1 = …`、`#M1: the left one`。
  - 紧贴名字的 `<` 或 `[` 是下标（6.11）。
  - 关键字的名字里，`-` 后面跟字母时才属于名字（关键字见 3.6）。`@GROUP- the pair` 是 GROUP 加自由文本。
- 自由文本可以写在括号外任意两个记号之间，也可以写在成员开头。
- **自由文本是语句的一部分。** 写在里面的引用不是说明，而是这条语句的对象：`Unlike #M2, #M1 @PLACE(x=0)` 把 M2 也放到了 x = 0。只作说明的文字写进注释（3.4），或者让它单独成为一个成员，用 `;` 与下一个成员隔开：只有自由文本的成员是空成员，忽略（4.1）。
- 标准不检查自由文本，自由文本不影响含义（原则 2.8）：`do not move #M2 @PLACE(x=30)` 仍会移动 M2。对否定词这类词，实现可以另给自己的警告（7.6）。
- 同理，误写的 `#M1.d` 里，`.d` 是自由文本，引用的是 M1 本身，不是它的漏极（给警告，见下）。
- 括号内没有自由文本。
- **警告。** 下面这些写错可能静默通过；它们给警告（7.6）：
  - 自由文本里的词与这一层的宿主元件名、看得到的 RNL 名字（不带前缀）或关键字名相同，如 `#M1 #M2 M3 @ALIGN("y")` 里的 `M3`、`WIRE {…}` 里的 `WIRE`：多半漏了 `#`、`%`、`$` 或 `@`。网络名常是普通词（如 in、out），不查。
  - 引用后面紧跟 `.` 加名字，如 `#M1.d`：端子用 `:` 写。
  - 引用后面紧跟 `-`、`!`、`'`、`+`、`/`、`*`、`\`、`^`、`~` 或 `|`，如 `&vdd!`、`#X1-a`：多半是名字里有这个字符，要加引号，如 `&"vdd!"`（3.6）；不加引号，引用就静默地指 `vdd` 或 `X1`。
  - 自由文本里的 `|`：管道写作 `=>`（4.2 第 3 条）。
  - 紧贴引用的 `:` 或 `::` 后面跟着非 ASCII 的词，如 `%c1::中点`：`::` 后面含非 ASCII 字符的名字要加引号，如 `%c1::"中点"`（3.6）；不加引号，`::` 和这个词是自由文本，引用指的是 `%c1`。
- 其余这类写错多数已经是错误：括号里没有自由文本，所以 `@ORIENT(MY)` 是错误；`#M1 @PLACE 1 2` 与签名不符；`#M1 (in_p)` 是错误，因为隔了空白的括号开始一个点，而 `(in_p)` 不是点（3.5）；`R1 -> R2` 里的 `>` 不能作自由文本。
- 给作者的写作参考由标准词表生成（5.3）。求解器和编辑器写的记录不应含自由文本。

### 3.4 注释

`/* … */` 可以写在任何允许空白的地方，包括括号内。注释不能嵌套，里面可以写任何字符。含有引用、或含有 `@`、`#`、`;` 这类字符的说明，写在注释里（3.3）。

### 3.5 空白与紧邻

- 空白是空格、TAB 和换行。记号不能拆开跨行，字符串也不能跨行。
- 以下位置不允许有空白和注释：前缀与名字之间；`:`、`::` 的两侧；名字与它的下标之间（6.11）；关键字与它的参数括号之间，以及 `@RNL` 与它的记录头括号之间（2.4）；对象与它的角色括号之间。
- 隔了空白或注释的 `(` 开始一个点（3.8）。所以 `#M1 @PLACE (10, 20)` 是 PLACE 加一个点，PLACE 没有参数：是错误。`#M1 (in_p)` 是 M1 加一个不合写法的点：也是错误。诊断建议去掉空白。
- 名字（加不加引号都一样）后面紧跟的 `<` 或 `[` 总是开始一个下标（6.11）。点写成 `(x, y)`，与下标不冲突；名字后面要写点，就用空白隔开，如 `&D (1, 2)`。下标里可以写空白和注释，如 `&D<1, 2:3>`（6.11）。
- 紧跟关键字的 `.` 是自由文本，如 `{#M1 #M2} @GROUP.` 里的句号；`@BUNDLE.LOCK` 是 BUNDLE 加自由文本 `.LOCK`（16.4）。

### 3.6 名字

- **不加引号的名字**是一个或多个 ASCII 字母、数字、下划线，按最长匹配取。
- **宿主名字**（`#`、`&` 之后）和端子名按宿主方言的规则（原则 2.1）：哪些名字合法，区不区分大小写，能不能以数字开头，如 `&0`。SPICE 不区分大小写，Spectre 区分。含别的字符的名字加引号，如 `#"M1<0>"`、`&"vdd!"`、`#XU1:"in+"`；引号里的写法与字符串相同（3.7）。名字后面可以紧跟下标：`#M1<0>` 就是 `#"M1<0>"`，`&D<7:0>` 是一组网络（6.11）。引号里的 `<` 或 `[` 是名字的一部分，不解析。
- **RNL 名字**（`%`、`$`、`?` 之后的名字，角色名，普通定义的参数名）：
  - 区分大小写：`$DIFFPAIR` 和 `$diffpair` 是两个名字。
  - `%`、`$`、`?` 后面的名字可以以数字开头，如 `%1st`。在没有前缀的位置（`(role)` 和 `parameter=`），不加引号的名字由 ASCII 字母、数字、下划线和任何非 ASCII 字符组成，不以 ASCII 数字开头，免得像数：`#M1(正输入)`、`@AS(间距=3) $X`。这两处都在括号里，括号里没有自由文本（3.3），所以不会把别的词吞进名字。
  - 可以加引号，含义相同：`$"a"` 就是 `$a`；引号只是转义。含别的字符的名字和非 ASCII 的名字写在引号里，如 `%"差分对"`、`%"input pair"`、`?"正输入"`、`%dp::"正输入"`。在角色名和参数名的位置上，非 ASCII 的名字可以不加引号（上一条），但空格或别的 ASCII 标点仍要加引号，如 `#M1("input pair")`。在角色名和参数名的位置上，加引号的名字永远是名字本身，不当代称。这一点不适用于 `$` 名字和 `::` 后面的名字，它们的非 ASCII 代称本来就写在引号里（16.5）。
  - 按写出的字符逐个比较，不做 Unicode 归一化。空名字是错误。
  - 不收下标（6.11）：后面紧跟 `<` 或 `[` 是错误，如 `%p<1, 2>`。点写成 `(1, 2)`，与名字之间隔空白。
- **代称**（16.5）在头段记录里声明，或来自代称包。关键字和标准词的代称可以含非 ASCII 的字母；它们只在 `@` 后面和括号里不加引号写。`$` 名字的代称照 `$` 名字写，非 ASCII 的加引号，如 `$"接地补位集"`。`#`、`&`、`%`、`$`、`?` 和 `::` 后面不加引号的名字如上所述只含 ASCII 字符，所以 `#M1和#M2` 是 `#M1`、自由文本 `和` 和 `#M2`。
- **关键字**只认大写，词间用 `-` 连接，如 `@AS`、`@SET-SYMBOL`；大写也便于在自由文本里认出它们。`@at` 是不认识的关键字，除非头段记录把它声明为代称（16.5）。
- **标准词**区分大小写，按标准的拼写写：参数名、记录头的字段名、子对象名、选择条件的名字和枚举值（如 `"x"`、`"low"`、`"MY"`）。指宿主东西的值（选择条件里的名字、模型名、网络名）按宿主的规则。别的写法可以通过代称接受（16.5）。
- **`true` 和 `false`** 保留，只认小写。它们不能作角色名或参数名。

### 3.7 字面量

- **数**是十进制。可以带正负号和前导零，可以省略小数点前的零或小数点后的数字，可以带指数：`0`、`+1`、`01`、`.5`、`1.`、`-2.5E-4`。`01` 就是 1，不是八进制。没有单位和工程后缀（`2u`、`10k` 是错误），没有十六进制数，没有 `NaN` 和 `Infinity`。位数不限。实现装不下一个值时，这条语句在这个实现里失效，报的错误说明这是实现的限制；不悄悄改值。坐标按容差比较（11.7）。
- **字符串**写在双引号里，不能跨行。引号之间的字符照原样取；只有 `"` 本身写成 `""`，如 `"say ""hi"""`。没有反斜杠转义：`\` 是普通字符，没有 `\n` 或 `\uXXXX`；非 ASCII 字符直接写。字符串里写不了换行；文字里的换行用文字记号 `\\` 写（13.6）。TEXT 有自己的反斜杠命令（13.6）；那是 TEXT 怎样读它的文字，不是字符串的转义。记录头里的字符串也这样写；这属于外层写法，不改（16.1）。
- **数组**写作 `[value, value, …]`。元素是字面量，数组可以嵌套。
- **真假值**是 `true` 和 `false`。
- 没有别的字面量。枚举写成字符串，如 `axis="x"`；没有 `null`、映射和构造值。
- 没有表达式：运算符是错误。

### 3.8 点

- 点写作 `(x, y)`，x、y 是数或 `_`（在普通定义的体里，也可以是参数空位，6.10）。`_` 让这一轴自由，由约束或求解器决定。
- 写一个点就是创建一个点对象（5.1）。
- 点没有算术；相对位置写成约束（第 14 章）。
- 点的 `(` 前面有空白或注释，或者紧跟在 `{`、`;`、`=>`、`=` 之后。紧贴关键字或对象的括号放它的参数或角色（3.5）。名字后面紧跟的 `<` 无论如何都是下标（6.11）。
