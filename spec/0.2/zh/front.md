# RNL 语言标准 0.2 版（中文版）

RNL（Rich Netlist）写在电路网表的注释里，描述电路怎样画成原理图、各部分是什么意思；电路本身只由网表定义。本文是这门语言 0.2 版的标准。

- 英文版 `rnl-0.2.md` 是正式文本。本文是它的中文译本；两者不一致时，以英文版为准。
- 标准词表 `rnl-words-0.2.json` 及其 JSON Schema `rnl-words.schema.json` 是本标准的一部分（5.3、附录 A）。
- RNL 的原则见 `rich-netlist.zh.md`（中文版，以英文版 `rich-netlist.md` 为准）；本标准称之为"原则"。
- 0.x 各版本之间不承诺兼容（16.1）。
- 本文整理自研究仓库 rnl-dev 的讨论草稿，提交 d668901 (2026-10-13)。
