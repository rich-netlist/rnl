## 付録 C 将来のバージョン向けの予約事項（参考情報）

本付録は本バージョンの標準が対象外とし、将来のバージョンで追加され得ると述べている事項を、言及している節とともに列挙する。本バージョンはこれらの項目のためにいかなるキーワードも記述形式も予約せず（5.3、16.4）、将来のバージョンがこれらを追加する義務もない。

| 将来のバージョンに残された事項 | 参照 |
|---|---|
| Eldoの `#com … #endcom` のようなブロックコメントを含むさらなるホストのキャリア、およびそれに伴うホストのコメント終端記号の扱い | 2.2、2.5 |
| レコードID；ツールは `type`、`author`、および文のkeyによって自身のレコードを見つける | 2.8 |
| 式 | 3.7 |
| 定義がセット全体に対して適用されるか、各メンバーに対して1回ずつ適用されるか（`each`）を明示する標準文 | 4.5 |
| 省略可能なスロット；それがないため選択は常に（`#` のみであっても）スコープを持つ | 5.3、10.1、13.7 |
| 1つの参照内で複数の添字を展開すること、および `<*2>A`、`A<0:2*2>`、`D[0..7]` のようなさらなる添字形式 | 6.11 |
| 標準診断コード | 7.6 |
| ファイル内で診断を抑制する方法、および（例えばレコードヘッダーのフィールドとしての）厳格モード | 7.6 |
| 複数の事実からなる単位：競合解決で事実がまとめて採用または破棄される定義または適用オブジェクト。未決事項：そのような単位の優先度、入れ子の適用オブジェクト、および `::` を通じて外から書かれる優先度 | 8.5 |
| シンボルおよびインスタンスの拡大縮小 | 9.2.1、11.7 |
| 配線の両端の矢印 | 9.2.5 |
| さらなる線種 | 9.3 |
| 色名および `rgb()` | 9.3 |
| パターン塗り、グラデーション、影 | 9.3 |
| 1つの文におけるセットの積集合 | 10.1 |
| パラメータによるプリミティブのシンボルの選択。各方言の一部のプリミティブでは、シミュレータが行の記述で種別を決める：SPICEでは `V=` で書かれたBソースは電圧源、`I=` で書かれたものは電流源である。サブサーキットやモデルはそのようには変化しない。1つの方法は `param=` のようなSELECT-INSTANCEの条件（行がこのパラメータを持つ）であり、もう1つは方言のアダプタがこれらのプリミティブに与える型（6.12）を `type=` で選択することである。端子数は `terminals=` で選択する（10.1）。それまでは標準パッケージは現行の規則で両方の種類を描画する | 10.1、6.12 |
| ORIENTによるセット全体の1ブロックとしての回転 | 11.2 |
| 1つのホストオブジェクトの、固有の名前を持つ別々のオブジェクトとしての複数描画 | 11.4 |
| オブジェクトのグループを囲む図形 | 13.4 |
| 配線上にアンカーされた注釈：配線に沿った位置（`t` や `offset` など）、および配線の途中にアンカーされたシンボルや矢印 | 13.3、15.2 |
| KiCadの `${R3:VALUE}` のような、`${…}` 内での他オブジェクトの属性への参照 | 13.6 |
| 制約における対角射影 `"x+y"` と `"x-y"` | 14.1 |
| 自身のレベルのみに適用されるUSE-PACKAGE | 16.2 |
| 複数ファイルに分割されたパッケージ | 16.2 |
| ネットリストとそのパッケージファイルのためのマニフェスト形式 | 16.2 |
| USE-PACKAGEの `digest=` パラメータのような、パッケージの内容ダイジェスト | 16.2 |
| 利用者に引き継がれる参照とは別の、パッケージが自身のためだけに使う参照 | 16.2 |
| `$acme.DIFFERENTIAL_PAIR` や `as=` のようなパッケージ修飾名、パッケージの別名、およびレベルタグ（名前の後の `.` 以外の形式で） | 16.2 |
| 拡張機構：必須拡張または任意拡張としてヘッダーレコードで宣言される、`@ACME.ROUTE` のようなベンダー接頭辞付きのキーワード | 2.8、16.4 |
| 厳密なRNL（すなわちソルバーなしで図面を描画できる条件）およびラウンドトリップの基準；これらはツール間の合意に委ねられる場合もある | 17 |
