## 부록 C 이후 버전을 위한 예약 사항(참고용)

이 부록은 이 버전의 표준이 제외하고 이후 버전에 나올 수 있다고 밝힌 사항들을 이를 언급하는 절과 함께 나열한다. 이 버전은 이 항목들을 위해 어떠한 키워드나 표기 형식도 예약하지 않으며(5.3, 16.4), 이후 버전에서 이들을 반드시 추가해야 하는 것도 아니다.

| 이후 버전으로 남긴 사항 | 참조 |
|---|---|
| 블록 주석(예: Eldo의 `#com … #endcom`)을 포함한 추가 호스트용 캐리어, 및 그에 따른 호스트 주석 종결자 처리 | 2.2, 2.5 |
| 레코드 ID; 도구는 `type`, `author` 및 구문의 key로 자기 레코드를 찾음 | 2.8 |
| 표현식 | 3.7 |
| 정의가 집합 전체에 적용되는지 각 멤버마다 한 번씩 적용되는지(`each`)를 나타내는 표준 문장 | 4.5 |
| 선택적 슬롯; 이것이 없으면 선택식은 적어도 `#`라도 항상 범위를 가짐 | 5.3, 10.1, 13.7 |
| 하나의 참조에서 둘 이상의 첨자 확장, 및 `<*2>A`, `A<0:2*2>`, `D[0..7]` 같은 추가 첨자 형식 | 6.11 |
| 표준 진단 코드 | 7.6 |
| 파일 안에서 진단을 억제하는 방법, 및 예컨대 레코드 헤더의 필드로서의 엄격 모드 | 7.6 |
| 여러 사실의 단위: 충돌 해결 시 사실들이 함께 유지되거나 버려지는 정의 또는 용례. 미결 사항: 그러한 단위의 우선순위, 중첩된 용례, 및 `::`를 통해 바깥에서 쓴 우선순위 | 8.5 |
| 심볼 및 인스턴스의 크기 조절 | 9.2.1, 11.7 |
| 배선 끝의 화살촉 | 9.2.5 |
| 더 많은 선 스타일 | 9.3 |
| 색상 이름 및 `rgb()` | 9.3 |
| 패턴 채우기, 그라데이션 및 그림자 | 9.3 |
| 하나의 구문에서 집합의 교집합 구하기 | 10.1 |
| 매개변수로 기본 소자의 심볼 고르기. 각 방언의 몇몇 기본 소자는 줄에 따라 시뮬레이터가 종류를 정한다. SPICE에서 `V=`로 쓴 B 소자는 전압원이고 `I=`로 쓴 것은 전류원이다. 서브서킷과 모델은 이렇게 달라지지 않는다. 한 가지 방법은 `param=`(줄이 이 매개변수를 가짐) 같은 SELECT-INSTANCE의 조건이고, 다른 방법은 방언의 어댑터가 이 기본 소자들에 주는 타입(6.12)을 `type=`으로 선택하는 것이다. 단자 개수는 `terminals=`로 선택한다(10.1). 그때까지 표준 패키지는 현재 규칙으로 두 종류를 모두 그린다 | 10.1, 6.12 |
| ORIENT로 집합 전체를 한 블록으로 회전하기 | 11.2 |
| 하나의 호스트 객체에 대한 여러 도면을 저마다의 이름을 가진 별개 객체로 두기 | 11.4 |
| 객체 그룹을 둘러싸는 테두리 도형 | 13.4 |
| 배선 위에 고정된 어노테이션: 배선 위의 위치(`t` 또는 `offset` 등), 및 배선 한가운데에 고정된 심볼이나 화살표 | 13.3, 15.2 |
| KiCad의 `${R3:VALUE}`처럼 `${…}` 안에서 다른 객체의 속성 참조하기 | 13.6 |
| 제약을 위한 대각선 투영 `"x+y"`와 `"x-y"` | 14.1 |
| 자기 레벨에만 적용되는 USE-PACKAGE | 16.2 |
| 여러 파일로 나뉜 패키지 | 16.2 |
| 넷리스트와 그 패키지 파일들을 위한 매니페스트 형식 | 16.2 |
| USE-PACKAGE의 `digest=` 매개변수 같은 패키지용 내용 다이제스트 | 16.2 |
| 패키지가 사용자에게 전달하는 참조와 분리하여 패키지 자체 용도로만 쓰는 참조 | 16.2 |
| 이름 뒤의 `.` 이외의 형식으로 된 `$acme.DIFFERENTIAL_PAIR`나 `as=` 같은 패키지 한정 이름, 패키지의 다른 이름 및 레벨 태그 | 16.2 |
| 확장 메커니즘: 필수 또는 선택 확장으로 헤더 레코드에 선언되는 `@ACME.ROUTE`처럼 벤더 접두사를 가진 키워드 | 2.8, 16.4 |
| 정확한 RNL, 즉 솔버 없이 파일을 그릴 수 있는 조건과 왕복 변환 기준; 이는 대신 도구들 사이에서 합의할 수도 있음 | 17 |
