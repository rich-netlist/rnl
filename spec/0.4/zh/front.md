# RNL 语言标准，0.4 版（草案）

RNL（Rich Netlist）写在电路网表的注释里。它描述电路怎样画成原理图，以及各部分是什么含义；而电路本身只由网表定义。本文件是这一语言 0.4 版的标准。

- 以英文正文为准。各语种译文按 `zh`、`ja` 等语言标签命名为 `rnl-0.4.<lang>.md`，仅供参考；两处说法不同时，以英文正文为准。
- 词表 `rnl-words-0.4.json` 及其模式 `rnl-words-0.4.schema.json` 是本标准的一部分（5.3、附录 A）。
- RNL 的原则见 `rich-netlist.md`（英文，为准；译本：`rich-netlist.<lang>.md`）；本标准称之为"原则"。
- 0.x 各版之间不保证彼此兼容（16.1）。
- 本正文依循研究仓库 rnl-dev 提交 {SOURCE} 中的 0.4 版草案对 0.3 版作了修订；附录 D 列出了变更内容。
