## 附錄 C 為後續版本保留的內容（參考性）

本附錄列出本版本標準未納入、且文中提及可能於後續版本加入的項目，並附帶提及它們的章節。本版本不為這些項目保留任何關鍵字或書寫形式（5.3、16.4），後續版本亦無須必定加入它們。

| 留待後續版本的項目 | 見 |
|---|---|
| 更多宿主的載體，包含區塊註解（例如 Eldo 的 `#com … #endcom`），以及由此帶來的宿主註解結尾處理 | 2.2、2.5 |
| 記錄識別碼；工具目前依 `type`、`author` 與敘述的 key 尋找其記錄 | 2.8 |
| 運算式 | 3.7 |
| 區分定義是套用於整個集合還是逐成員套用（`each`）的標準例句 | 4.5 |
| 可選槽位；沒有可選槽位時，篩選一律有作用域，哪怕僅為 `#` | 5.3、10.1、13.7 |
| 單一引用中展開多個下標，以及更多下標形式，例如 `<*2>A`、`A<0:2*2>` 與 `D[0..7]` | 6.11 |
| 標準診斷代碼 | 7.6 |
| 在檔案中抑制診斷訊息的方式，以及嚴格模式（例如作為記錄標頭欄位） | 7.6 |
| 多項事實構成的取捨單位：衝突取捨時將定義或用例的所有事實一起保留或一起捨棄。尚待確定：此類單位的優先順序、巢狀用例，以及從外部透過 `::` 寫出的優先順序 | 8.5 |
| 符號與實例的縮放 | 9.2.1、11.7 |
| 連線端點的箭頭 | 9.2.5 |
| 更多線型 | 9.3 |
| 顏色名稱與 `rgb()` | 9.3 |
| 圖樣填色、漸層與陰影 | 9.3 |
| 單一敘述中的集合交集 | 10.1 |
| 依基本元件的參數選擇符號。對於各類方言中的少數基本元件，模擬器依網表行決定其種類：在 SPICE 中，寫有 `V=` 的 B 源是電壓源，寫有 `I=` 的則是電流源。子電路與模型不會如此變化。一種方式是 SELECT-INSTANCE 新增諸如 `param=`（該行擁有此參數）的條件；另一種是由該方言的配接器為這類基本元件給出類型（6.12），再以 `type=` 選取。端子數量則以 `terminals=` 選取（10.1）。在此之前，標準套件依現行規則繪製這兩種基本元件 | 10.1、6.12 |
| 使用 ORIENT 將整個集合作為單一區塊旋轉 | 11.2 |
| 單一宿主物件的多個繪圖，作為各自擁有獨立名稱的個別物件 | 11.4 |
| 框住一組物件的圖形 | 13.4 |
| 錨定於連線上的標註：沿著連線的位置（例如 `t` 或 `offset`），以及錨定於連線中段的符號或箭頭 | 13.3、15.2 |

| 僅供套件自身使用、不傳遞給其使用者的引用 | 16.2 |
| 套件限定名稱、套件別名與層級標籤（如 `$acme.DIFFERENTIAL_PAIR` 或 `as=`），採用名稱後方接 `.` 以外的形式 | 16.2 |
