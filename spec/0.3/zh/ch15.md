## 15 电气语义

### 15.1 语义套用

```rnl
%dp1 = #M1(in_p) #M2(in_n) #M5(tail) @AS $DIFFERENTIAL_PAIR;
%cm1 = {#M3 #M9}(ref) {#M4 #M6}(out) @AS $CURRENT_MIRROR;
%in = {#M8 #M5} @AS $MATCHED
```

- 对象的含义用 AS 套用语义定义来标记（9.5）：套用产生一个用例，对象填进定义的角色表里的各个角色。标记含义与写布局关系是同一种语句。
- 用例可以作为别的用例的成员（嵌套），见 9.4、10.1 的例子。
- 集合角色在角色表里写成 `"{name}"`（如例子里 `$MATCHED` 的 `"{members}"`，`$DIFFERENTIAL_PAIR` 的 `"{tail}"`，`$CURRENT_MIRROR` 的 `"{ref}"` 和 `"{out}"`），收一个集合，表达个数不定的成员（9.4）。
- 角色可以声明收哪种对象，如 `roles=[["in_p", "instance"], ["in_n", "instance"]]`；填了种类不对的对象，整个套用失效（9.4）。体为空的定义不检查角色填的是什么，不声明就查不出填错。
- 用例的角色名是它的子对象，如 `%dp1::in_p`。
- 套用定义时展开它的体，体里可以有约束，如优先级为 `"low"` 的默认画法，用例的优先级能关掉它（9.5、14.8）。
- 不校验：不检查含义是否符合网表的连接、类型或参数（原则 2.4）。如 `#M3(ref) #M4(out) @AS $CURRENT_MIRROR` 不检查 M3 的栅极和漏极是否相连。
- 选出某种含义的用例用 SELECT-USAGE，选出含有某个对象的用例用 SELECT-ANCESTOR-USAGE；用例的成员用以用例为范围的选择取到（10.1）。
- 语义定义的词汇归标准包（9.5），标准包提供 `$DIFFERENTIAL_PAIR` 等定义。
- 单条描述的基本合法性（原则 2.4）是：它的引用找得到，它的角色收到种类正确的对象，它的单个角色都填了，它展开出的每条语句自身合法（9.5）。不检查两个角色是否填了同一个对象。

### 15.2 电流方向：CURRENT

```rnl
#M5:1 @CURRENT("in");                 /* drain: the current flows in */
#M5:3 @CURRENT("out")                 /* source: the current flows out */
```

- CURRENT 设定端子上静态电流的方向：`"in"`（流入）、`"out"`（流出）或 `"unspecified"`（不定，用来覆盖包里规则给的值）。参数是 `direction`。
- 它是关于端子的事实。它与 ORIENT 一样是修改语句，沿用输入的句柄。它有键，每个端子一个，后写的生效。从没写过它的端子就是不定。
- 它只给在端子上。多端子器件内部的电流拆不清楚：三端器件说"a 流向 b、b 流向 c"，b 处是流入还是流出说不清；而端子上静态电流的方向总有确定的含义。
- 它只收宿主的端子，含本层的端口：`#:inp @CURRENT("in")` 的意思是电流从这里流进子电路。虚拟元件的端子电气上不存在：收到时 CURRENT 失效。没有引脚的端子也可以（与导线不同）。
- 不校验：既不对照网表检查，也不检查各端子的方向是否自洽（原则 2.4）。
- 用途：电流流出时，端子上电流的走向就是导线离开引脚的方向（9.2.4，随符号的朝向转）；流入时反过来。求解器可以用它在摆法里挑，比如尽量让电流朝下（14.8）；朝上还是朝下是风格。没有写 CURRENT、写的是 `"unspecified"`，或者引脚没写 `direction=`（9.2.4）的端子，不给出方向；实现从图形推断出来的方向，在这里不算。规则可以按端子的电流方向选端子，用 SELECT-TERMINAL 的条件 `current`（10.1）。
- **箭头**：CURRENT 不画东西。按 CURRENT 画不画箭头、怎样画，是查看器的偏好（属于它的风格），与显示哪些网名同类（13.3）。查看器自己画时，跳过已有标准电流箭头用例的端子，就像它认得标准的 `$NO_CONNECT`（12.6）。要保留的箭头（导入的原图里的，或作者定下的）写成显式的对象：

  ```rnl
  $CURRENT_ARROW @ATTACH #M5:1 => @ORIENT("R270") => @TEXT("I_{SS}", dx=1);   /* on the drain pin, with I_SS beside it */
  $CURRENT_ARROW @ATTACH (12, 20) => @ORIENT("R270")                           /* in the middle of a wire, at absolute coordinates */
  ```

  - 画在端子上的箭头是主对象为端子的用例（12.1）。它不跟着引脚转，所以朝向要写出来；旁边的文字附着在这个用例上（13.3）。
  - 导线中间的箭头不锚定在导线上：它画在一个点上，用绝对坐标。
  - 流入和流出怎样区分，箭头的定义和符号怎样画，归标准包。符号可以只是一条末端带箭头的线（9.2.5）。
  - 画出来的箭头与 CURRENT 分开：两者若是一回事，导出一个箭头就会改变布局的目标。
