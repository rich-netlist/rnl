RNL Viewer 0.5.2 lists the usages of the selected object, shows groups as a kind of usage, sets nested frames out so that their titles show, and can carry the public packages for use offline. It is built from the same source as the web viewer, which already has what is here but the packages; this release brings it to the desktop viewer. The core's part of these changes (the usages of an object, groups, the RNL package format) reaches the `rnl` command and the npm package with the next core release.

## Usages

- **The usages of the selected object.** When an instance, a net or a terminal is selected, the lower half of the Usage panel lists the usages it is a member of, a sentence a row, such as "in_p of usage %dp1 (definition $DIFFERENTIAL_PAIR)", each language in its own word order, with the usages those are members of in turn indented under it. A usage that is not in effect is grey, with its state. While the pointer is on a row, the usage's members are lit in the drawing; a click selects the usage. In the netlist text, the context menu of a reference such as `#M1` has **Show its usages**, and **View › Show Roles on Hover** (off to begin with) adds the object's first usage to the box beside the pointer.
- **Groups (`@GROUP`) are a kind of usage.** The Usage panel lists them last, under `@GROUP`, folded to begin with like every kind, with a checkbox for each. The drawing frames a group, titled `@GROUP: %core`, and selecting one lights up its members. A group that `PRIORITY` has turned off is grey in the list, with "disabled", and its frame is drawn faint. The table of an object's usages says which groups it is a member of and which groups those are within, *%amp is in turn within group %core*.
- **Nested frames are set out.** A frame that holds other frames, of usages and groups alike, goes one title's height outside the frames within it, and its title with it, so that an outer frame's title is no longer covered by an inner one's; a title that would lie on another's goes down a row. Only the outer three frames of a nest are set out, the frames below are drawn over one another, and only the frames shown are counted, so a few kinds shown at a time are set out among themselves. Export SVG and Export PNG set the frames out the same way.
- **The kinds of usages start folded.** When a file opens or the level changes, every kind in the Usage panel is folded; **Expand All** (and **Collapse All**) above the list opens or folds them all. A usage you select, on the drawing, in the text or in the table of an object's usages, opens its kind and comes into view.

## Public packages

- **The desktop viewer can carry the public packages**, for use offline; it never downloads them. The Windows installer (`setup.exe`) has a "Public packages" page, on by default (`/PACKAGES=0` leaves them out of a silent install), and the MSI a "Public packages" feature (`PUBLICPACKAGES=0`). The Debian package comes in two files, the viewer and, separately, the public packages. The portable builds come in two variants, without and with the packages: the single Windows file and a zip of it beside a `public-packages` folder, the AppImage, and the disk images of macOS.
- The packages are the latest versions in the catalog of [rnl-packages](https://github.com/rich-netlist/rnl-packages) when the release was built, each file checked against its SHA-256, under their licences (CC0-1.0). The Library lists them as a read-only group, "Public packages (bundled)", and a package that a netlist uses by name is found there. **Help › Public Packages** says what the packages are, which this build carries, where the other variant is, and how to add a folder of downloaded packages to the PATH.

## Files

- **A file that is no netlist is shown as plain text.** A Verilog-A, Verilog or VHDL file gets no netlist or RNL highlighting, folds, tints or include links, and says so in the drawing's place; so does any file the core takes for text, or that you set to Text in the Library. A file you set to SPICE is a netlist again.
- **A package file is known by its format**, not its `.rnl` suffix. In the Library, `.pkg` and `.rnl` files show their format, and a `.pkg` that has a `PACKAGE` header is "Automatic (RNL package)"; either can be set to another format.

## Interface

- The Problems panel's first column is as wide as the widest name of a severity, so that the longer words of Spanish, French and German no longer run into the message.
- On a phone, the Symbol view's preview takes two fingers to zoom and drag, one finger to drag and a double tap to fit it again, as the drawing does.
- The Japanese, Spanish and German of the usage table were corrected as a review found them; Traditional Chinese and German write "apply" (the edits) with a word of its own, apart from RNL's term; Simplified and Traditional Chinese write "Agent" in English, capitalized.
- **Solve** (desktop) tells supply, ground and port symbols by their drawing, not by their names in the standard 0.2, so that it places the grounds and ports of files of 0.3 as it should.

## The web viewer

These are in the web viewer, which this release's changes come from; the desktop viewer reads its page from disk and has no use for most of them.

- **It starts faster.** The page asks for its scripts, the core and the files it reads at start all at once, reads only the catalog of the language it starts in, and, for Chinese and Japanese on a computer with no font of its own for them, takes the characters of its interface from one small font of about 100 KB in place of megabytes of slices. On a slow connection the first visit is usable about two seconds earlier, and a visit after the cache has expired, much sooner.
- An embedded viewer (`?embed=1`) takes `usages` and `currents` in its address and in messages, and starts without the usage frames and with the current directions.

Windows requires 64-bit Windows 10 or 11 and Microsoft Edge WebView2. The installers download WebView2 when it is missing. Linux requires x86_64, WebKitGTK 4.1 and a glibc version compatible with Ubuntu 22.04 or newer.

The macOS app has an ad-hoc signature only, with no Developer ID and no Apple notarization. If macOS blocks the first start of a download you trust, choose Open Anyway in System Settings › Privacy & Security, or run `xattr -dr com.apple.quarantine "/Applications/RNL Viewer.app"`.

The downloads are not code-signed with a publisher certificate. Windows may display a SmartScreen or unknown-publisher warning. Verify downloads against `SHA256SUMS.txt`, for example with `shasum -a 256` on macOS.
