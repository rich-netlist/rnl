RNL Viewer 0.1.4 improves navigation through large designs, adds English and Simplified Chinese UI, and makes the netlist and symbol panels more useful. The desktop and [web viewer](https://rich-netlist.github.io/rnl/viewer/) share the changes below unless a platform is named.

## Include scope and Library

- **Auto Include is enabled by default.** When normal includes leave a subcircuit undefined, the viewer looks it up in an index of the current Library. A unique match is loaded and reported as a warning with its source file. Conflicting definitions require an explicit include. File > Auto Include and the Netlist checkbox control the same saved setting; source files are not rewritten.
- **Auto Include uses the actual definition file.** A definition discovered through a testbench is loaded from its own file when possible. This fixes accidental imports of unrelated testbenches, circular includes back to the opened file, and the resulting drawing errors. Explicitly selected library sections retain their required context.
- **Cross-file navigation opens an independent document.** Descending to a subcircuit in another file uses that file's own includes and the current Auto Include setting. It does not inherit the parent testbench's includes. Descent, ascent and breadcrumbs retain a visit history independently of include scope; other navigation starts a new history. Each visited file joins Library.
- **PATH lists netlists as well as packages** on the desktop. **File > Reload Library** rereads library files and packages, rescans PATH, rebuilds the subcircuit index and refreshes the document. Applied edits use a local index without changing another document's cached definitions.

## Navigation and performance

- **Desktop compilation and drawing cache.** Returning to a file can reuse its compiled document and SVG. File > Memory Cache shows usage, sets the memory limit, clears retained results or disables caching. The default limit is 256 MiB; old entries are evicted as needed, and changed dependencies invalidate cached results.
- **Desktop background preloading.** After a period of inactivity, one background compiler prepares nearby subcircuits and Library/PATH files, including SVG generation. It yields between files, pauses new work during interaction, and discards superseded work. Prefetched results share the cache limit and cannot evict documents already visited. Background preloading can be disabled in File > Memory Cache.
- **Smoother file switching.** Large source panels and diagnostic lists do less work at navigation time, drawing-related layout is bounded, and fast cached transitions avoid flashing a loading overlay.
- **Number keys select side panels:** 1 Library, 2 Netlist, 3 Hierarchy, 4 Symbol, 5 Not drawn, and 6 Solve on the desktop. A number opens the panel if hidden. View > Side Panels marks the current panel and includes Hide.

## Source and symbol inspection

- **The Netlist panel follows the displayed circuit's file.** Its full path appears as plain text, shortened in the middle when necessary, with options on the next row. Include filenames are links; Shift-click opens the target in a new window.
- **RNL highlighting and filters.** Valid RNL has a light blue background, with a darker blue for statements containing free text. RNL only hides the netlist; its Semantics only option keeps the free-text RNL statements. Failed statements controls whether inactive grey lines appear. Highlighted netlist names change text colour.
- **Fold subcircuits** with the plus/minus controls beside line numbers. The Not drawn tab shows the current count when it is nonzero.
- **A new Symbol panel** shows the symbol used for the current circuit, including the definition supplied by its parent instance when applicable. Its embedded preview pans and zooms, offers fit/zoom controls and optional bounds, origin, pins and labels, and keeps the background transparent over the grid. The panel also lists pins and labels and shows the original definition with its source path.

## Language, Windows integration and web imports

- **Switch between English and Simplified Chinese UI** in View > Language. The choice is remembered. Parser and solver diagnostics retain their original English text.
- **Windows file associations and native drag-and-drop.** Installers register RNL Viewer as an available application for netlist files, including `.sp`, `.spi`, `.scs` and `.netlist`. Choose it in Windows Default apps or Open with; an existing default is not replaced automatically. Files dragged from Explorer can be opened directly.
- **Public packages come from the shared package catalog.** Optional packages are downloaded and verified separately from the built-in standard packages. The complete web viewer and embedded viewer share the import API for text, URLs and package requests, including request IDs and cancellation of superseded imports.

Windows requires 64-bit Windows 10 or 11 and Microsoft Edge WebView2. The installers download WebView2 when it is missing. Linux requires x86_64, WebKitGTK 4.1 and a glibc version compatible with Ubuntu 22.04 or newer. For macOS, build from [source](https://github.com/rich-netlist/rnl/tree/viewer-v0.1.4/apps/desktop).

The downloads are not code-signed. Windows may display a SmartScreen or unknown-publisher warning. Verify downloads against `SHA256SUMS.txt`.
