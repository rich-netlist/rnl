The fourth release of RNL Viewer, the desktop viewer of Rich Netlist (RNL). Since 0.1.2 it moves through a design's levels from the keyboard and opens a level or a copy of the page in a new window, edits the text in a mode that applies it on leaving, shows its progress while it starts and opens files, reads large netlists quickly, frames grounds, supplies, ports and junctions when they are selected, and has the RNL logo as its icon. Its built-in packages are now the standard series alone. The web viewer, https://rich-netlist.github.io/rnl/viewer/, shares the page and gets what is not marked as the desktop's.

## Changes that may need action

- **Only the standard series is built in.** The viewer bundles the standard series 0.2 and 0.3, including `rnl-zh`, and no other package. A netlist that uses `analog-canvas-extensions` now needs its package file, in a directory of the search path or included in the Library tab. When it is missing, Problems says so and links to the page of the packages, https://rich-netlist.github.io/rnl/en/packages.html, where the public packages are published.
- **`rnl-pdk-sky130` is now `pdk-sky130`**, with no alias, so a netlist that uses the SkyWater SKY130 symbols names the package `pdk-sky130`. Names that begin with `rnl-` are kept for the standard's own packages.

## What is new since 0.1.2

- **Moves through levels from the keyboard.** E or Enter opens the subcircuit of the selected instance, and Ctrl+E or Backspace goes up to the parent level. Shift+E or Shift+Enter opens the subcircuit in a new window, and the window it came from keeps its document, level and selection.
- **Opens new windows.** File › New Window opens another window with the same source, level, selection, Library and settings. On the desktop each window is a process of its own, placed a little below and to the right of the one it came from. A new window reads the files from disk again, so when the current one has applied changes that are not saved, it asks first.
- **Edits in a mode.** Ctrl+Q enters and leaves editing; it is the Control key on every system, so that it never quits the app on macOS. Leaving applies the text. Apply and Exit Editing (Ctrl+Enter) leaves even when Problems reports an error, and Discard Changes asks before it drops the text. The first visible line and the caret stay where they were when the mode changes.
- **Keeps the side panel steady.** Clicking a file in the Library tab keeps that tab open, and right-clicking the side panel no longer shows the browser's own menu, except in text fields, where copy and paste stay available.
- **Shows its progress.** While it starts, the window shows RNL Viewer and its version until the page is ready; on Windows they appear at once, before WebView2 has started. Opening a file shows its stages, reading, parsing and displaying, with a progress bar.
- **Reads large netlists quickly.** The netlist panel draws only the lines in view, so a long netlist opens and scrolls quickly. Find, selecting and copying, and going to a problem or an instance still cover the whole file.
- **Frames virtual symbols.** Selecting a ground, a supply, a port or a junction frames that symbol by its box, as an instance is framed. Selecting a network still marks its pins and frames no symbol.
- **Places labels positioned in the scene where they belong.** A label whose position on both axes comes from PLACE or from dx and dy no longer takes the orientation of a mirrored or rotated part; it used to have its alignment flipped and so moved onto the part. This follows the clarification of RNL 0.3, 13.3.
- **Works with the public packages eda-symbol and eda-style**, published on the page of the packages: eda-symbol has 137 schematic symbols, and eda-style draws green hairlines, red text, monospaced labels and square terminals, for the standard symbols, eda-symbol's or your own. Add their files to the search path or the Library to use them. For them, text in a monospaced font is measured with a fixed width for each ASCII character, and exported SVG files name the font asked for.
- **Has the RNL logo as its icon**, on a navy ground, with versions drawn to the pixel for the small sizes of the taskbar, the title bar and lists of files.

## Requirements

Windows 10 or 11, 64-bit, with the Microsoft Edge WebView2 runtime, which Windows 11 and an up-to-date Windows 10 have. When it is missing, the installers download it from Microsoft and install it, which needs a connection to the internet; for the single file, install it from https://developer.microsoft.com/microsoft-edge/webview2/.

Linux on x86_64 with glibc as recent as Ubuntu 22.04's and WebKitGTK 4.1. The deb brings what it needs through apt; the AppImage bundles most of it but cannot make an older glibc work.

For macOS, build the viewer from the source: see [`apps/desktop`](https://github.com/rich-netlist/rnl/tree/viewer-v0.1.3/apps/desktop).

## Not signed

The files are not code-signed, so Windows may warn before running one: SmartScreen's "Windows protected your PC", where More info > Run anyway runs it, or an unknown publisher when the MSI asks for administrator rights. Check a file against `SHA256SUMS.txt` before you run it.
