The second release of RNL Viewer, the desktop viewer of Rich Netlist (RNL). Since 0.1.0 it edits, applies and saves the text, solves a netlist as a preview, lists the objects it does not draw, reads RNL 0.3 and more of the netlists written in practice, and shows names and picks objects more easily. The web viewer, https://rich-netlist.github.io/rnl/viewer/, shares the page and gets what is not marked as the desktop's.

## What is new since 0.1.0

- **Edits the text, applies it and saves it** (the web viewer too, which downloads the file instead of saving it). Edit > Edit Text (Ctrl+E) gives a text box for each file; the changes are not applied until Edit > Apply Changes (Ctrl+Enter) builds the netlist again from the texts in memory. Nothing is written until File > Save (Ctrl+S), which writes only the files you changed, each in its own encoding and line ends; File > Save As writes the netlist opened and opens it. Reloading, opening another file and closing the window ask first.
- **Does not save over a file another program changed** since the viewer read it: if one changed or is gone, nothing is written, and a dialog asks Overwrite, Reload or Cancel.
- **Solves a netlist as a preview** (the desktop only). Solve > Solve (F9) places the objects as `rnl solve` would, on a background thread with a Cancel in the status bar, and draws the result without writing any file; the Solve view lists, level by level, the facts that failed, were discarded, are undecided or kept. Solve > Save Solved Copy As (Ctrl+Shift+S) writes one file, or a folder when there are includes, and never over a file that was read; a file of 0.2 is raised to 0.3. Solve > Settings sets the solver's options, such as the time limit, the tolerance, the grid and the budget, and the order of its objectives, and remembers them.
- **Lists what it does not draw.** An object without a position is not drawn until a solver places it; the Not drawn view of the side panel, counted in its tab, lists them with their symbols and the nets at their pins, 20 rows at a time as you scroll, searched by name, and a row goes to its statement, which the text greys. A transistor whose model card the netlist does not have is no longer drawn as an N-type device by its first letter: it is listed there with the reason "model card not found", and the reading warns once for each missing model. The drawings of the list are made as it scrolls, not all at once, so a netlist with tens of thousands of such objects builds faster and its Document is several times smaller.
- **Finds the subcircuits nothing calls.** The Hierarchy lists the subcircuits that the top level does not reach, each with what it calls; a file whose top level has no objects opens on the first of them that has something to draw, and an empty level says why it shows nothing.
- **Shows names, selects labels, and asks which object you meant.** View > Show Names on Hover, on to begin with, shows the name of the instance or net the pointer rests on, beside the pointer; a ground, supply or junction that the netlist does not name shows nothing. A click on a label selects the instance or net it is attached to, and a selected object's labels are marked. A click on several objects at once, such as a wire over a symbol, opens a list beside the pointer to choose from, with the mouse or Up, Down, Enter and Escape.
- **Reads RNL 0.3** by default, and still reads a file of 0.2 as before, with the standard series 0.2. The standard series 0.3 and the Analog Canvas extensions are bundled, and a solved copy is written as 0.3.
- **Draws more devices as they should look.** A P-type JFET is drawn with its source at the top, as the P-type MOS and bipolar transistors are, and the controlled sources `$VCVS`, `$VCCS`, `$CCVS` and `$CCCS` are drawn as a diamond, so that a dependent source no longer looks like an independent one.
- **Reads more netlists right.** SPICE element lines that an outside review of devices and dialects found misread: a MOS with three nodes, MOS and BJT lines with five nodes or a model card it cannot see, a BJT with an area, binned models, values written as `r=`, `c=`, `l=`, `dc=`, `V=` or `I=`, spaces around `=`, and E and G sources with `VALUE`, `TABLE`, `LAPLACE` or `POLY`; Spectre netlists with binned models, parameters with spaces around `=`, `tline` and more model families; Spectre's switch, relay and transformer; the ports of a `.subckt` written over continuation lines; a file that is not a `.scs` file, which starts in SPICE mode; a library section, which is read as a file of its own; and regions written to be encrypted, which are read with a warning.
- **Fixes.** A file of 200 000 lines opens, and characters outside the Basic Multilingual Plane, such as emoji, no longer move the places marked in the text; Enter right after the up button reached the top level no longer goes to the hidden button.

## Requirements

Windows 10 or 11, 64-bit, with the Microsoft Edge WebView2 runtime, which Windows 11 and an up-to-date Windows 10 have. When it is missing, the installers download it from Microsoft and install it, which needs a connection to the internet; for the single file, install it from https://developer.microsoft.com/microsoft-edge/webview2/.

For Linux and macOS, build the viewer from the source: see [`apps/desktop`](https://github.com/rich-netlist/rnl/tree/viewer-v0.1.1/apps/desktop).

## Not signed

The files are not code-signed, so Windows may warn before running one: SmartScreen's "Windows protected your PC", where More info > Run anyway runs it, or an unknown publisher when the MSI asks for administrator rights. Check a file against `SHA256SUMS.txt` before you run it.
