The first release of RNL Viewer, the desktop viewer of Rich Netlist (RNL): it opens a SPICE or Spectre netlist and draws the circuit that the netlist's RNL records describe. It only reads: it neither edits nor solves, so objects without a position are not drawn.

## What it does

- **Opens a netlist**: a SPICE netlist, a Spectre netlist (`.scs`) or an RNL package (`.rnl`), from File > Open or the command line. File > Reload (F5) reads it again and keeps the level, the view and the selection.
- **Draws one level at a time**, the top level or a subcircuit, with the standard packages it bundles, in the fonts it ships, so that texts are laid out alike on every computer. Drag to move the view, scroll to zoom; F fits the level to the window.
- **Shows the netlist**: its text and the files it includes, with RNL and the host statements highlighted, and the problems: errors, warnings and hints, each with its line. The statements that do not take effect are marked.
- **Follows a selection** between the drawing and the text: a symbol selects its instance and a wire its net, and the text marks every place that names it; a click in the text selects on the drawing.
- **Goes down into subcircuits** and back up: Enter or a double click opens a selected subcircuit instance, Backspace goes back up. The Hierarchy view lists the instances as a tree and every subcircuit by name.
- **Checks for updates when asked**: Help > Check for Updates looks for a newer release here, and never looks by itself.

The same viewer runs in a browser, with nothing to install: the web viewer, https://rich-netlist.github.io/rnl/viewer/, opens files from your computer, a folder or a URL, and reads them in the page.

## Files

| File | |
| --- | --- |
| `RNL-Viewer-0.1.0-windows-x64-setup.exe` | The installer for most people. It installs for you alone, without administrator rights, in English or Simplified Chinese as Windows is set, and adds RNL Viewer to the Start menu, to the desktop and to the installed apps, from which it uninstalls. |
| `RNL-Viewer-0.1.0-windows-x64.msi` | The installer for all users of a computer, into Program Files; it needs administrator rights, and suits deployment with `msiexec /i RNL-Viewer-0.1.0-windows-x64.msi /qn`. |
| `RNL-Viewer-0.1.0-windows-x64.exe` | The app as a single file, to run without installing. |
| `SHA256SUMS.txt` | The SHA-256 sums of the three, to check a download: `Get-FileHash RNL-Viewer-0.1.0-windows-x64-setup.exe` in PowerShell, or `sha256sum --check SHA256SUMS.txt`. |

## Requirements

Windows 10 or 11, 64-bit, with the Microsoft Edge WebView2 runtime, which Windows 11 and an up-to-date Windows 10 have. When it is missing, the installers download it from Microsoft and install it, which needs a connection to the internet; for the single file, install it from https://developer.microsoft.com/microsoft-edge/webview2/.

For Linux and macOS, build the viewer from the source: see [`apps/desktop`](https://github.com/rich-netlist/rnl/tree/viewer-v0.1.0/apps/desktop).

## Not signed

The files are not code-signed, so Windows may warn before running one: SmartScreen's "Windows protected your PC", where More info > Run anyway runs it, or an unknown publisher when the MSI asks for administrator rights. Check a file against `SHA256SUMS.txt` before you run it.
