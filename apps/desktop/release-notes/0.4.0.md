RNL Viewer 0.4.0 lets you set the format each file is read in, adds a few keys and settings, and makes the panel keys work while the viewer is still starting. It goes with RNL core 0.4.0, which reads each file of a netlist in its own format.

## Parse format of each file

- **A format chip on each netlist in the Library.** Each netlist row, and each file the netlist shown includes, listed under it, ends with a chip naming the format the file is read in: SPICE or Spectre. A muted chip means the format is chosen automatically; a solid one means you chose it.
- **Click the chip to change it.** The menu offers Automatic, with the format it detects, and each format the core knows. A choice reads the netlist again at once and keeps your edits.
- **Automatic** reads a `.scs` file, or a file with `simulator lang=spectre` among its first 50 lines, as Spectre, and any other file as SPICE. Each file is read by its own format, not by the main file's.
  - So a SPICE netlist that includes a `.scs` file now reads that file as Spectre, and a Spectre netlist that includes a SPICE file reads it as SPICE. Netlists whose files are all of one format read as before. The [core's notes](https://github.com/rich-netlist/rnl/releases/tag/core-v0.4.0) list what changes.
- **Choices are remembered.** The desktop keeps them in its settings, by file. The web viewer keeps a choice for a file it read from a web address, and a choice for a file you opened from your computer only while the page is open.

## Keys and settings

- **Shift+R shows and hides current directions** (View › Show Current Directions). R alone does nothing, and a capital R typed in a text box stays text.
- **Panel keys work at once during startup.** The number keys 1–7 switch the side panel as soon as the viewer appears, before the first netlist has been read. On the web this no longer waits for the core, which can take a while where the browser runs WebAssembly slowly. A key pressed while the page is still loading runs once it has started.
- **Second highlight colour.** View › Color Scheme has a new colour, *Subcircuit selection highlight (drawing)*, below *Selection highlight*: the colour of a selected subcircuit instance that can be opened, red by default as before. The drawing lightens it on a dark background. The netlist keeps its own highlight.
- **The right-drag zoom rectangle keeps the normal highlight colour**, also while a subcircuit instance is selected. It used to turn red with the selection.
- **Diagnosing keys that do nothing.** With `?debug=keys` in the web viewer's address, a corner of the page lists the last keys and focus changes and what became of each key. If the keys do not reach the page at all, try a private window or turn off browser extensions one at a time.

## Desktop

- **Add PATH with Sub-folders…** in the Library adds a folder and all its sub-folders to PATH, searched in order. The group says *with sub-folders*. At most 500 sub-folders of one entry are searched, and the group says so when a folder has more; hidden folders and links are skipped. **Add PATH Directory…** is now **Add PATH…**.
- **Linux: the deb recommends a Chinese font.** It recommends `fonts-noto-cjk`, which apt installs with it by default, for the GTK menus, native tooltips and file dialogs that cannot use the viewer's own font. It is not required: `--no-install-recommends` leaves it out.

Windows requires 64-bit Windows 10 or 11 and Microsoft Edge WebView2. The installers download WebView2 when it is missing. Linux requires x86_64, WebKitGTK 4.1 and a glibc version compatible with Ubuntu 22.04 or newer.

The macOS app has an ad-hoc signature only, with no Developer ID and no Apple notarization. If macOS blocks the first start of a download you trust, choose Open Anyway in System Settings › Privacy & Security, or run `xattr -dr com.apple.quarantine "/Applications/RNL Viewer.app"`.

The downloads are not code-signed with a publisher certificate. Windows may display a SmartScreen or unknown-publisher warning. Verify downloads against `SHA256SUMS.txt`, for example with `shasum -a 256` on macOS.
