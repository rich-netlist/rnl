RNL Viewer 0.3.0 shows current directions, draws lighter usage frames from the core's geometry, and keeps a file's encoding when it saves. The desktop and [web viewer](https://rich-netlist.github.io/rnl/viewer/) share the changes below unless a platform is named. This release goes with RNL core 0.3.0 (`core-v0.3.0`), whose fixes it includes.

## Inspection overlays

- **View > Show Current Directions** draws an arrow at each terminal with `@CURRENT("in")` or `@CURRENT("out")`, including explicit subcircuit port symbols. It is off to begin with, and the setting is remembered.
- **Usage frames come from the core.** The frames, titles and role labels are placed from the geometry the core gives. `rnl render --usages --currents` draws the same overlays ([decision 0014](https://github.com/rich-netlist/rnl/blob/main/docs/decisions/0014-inspection-overlay-geometry.md)).
- **Lighter frames.** A usage frame is now a 1pt dotted border with a 10% fill; when selected, 2pt with a 20% fill. The border keeps its screen width while zooming.

## Saving and encodings (desktop)

- **Saving keeps the file's encoding**: UTF-8, with its byte order mark when it had one, or Latin-1. If an edit adds a character that Latin-1 cannot hold, nothing is saved and the message names the character.
- **New commands to convert explicitly:**
  - File > Save Changes Using UTF-8;
  - File > Save As UTF-8...;
  - Solve > Save Solved Copy As UTF-8...
- **No partial batches on encoding errors.** All changed files are encoded before any is written, so an encoding error leaves every file unchanged.

## Library and startup

- **Long paths stay on one line.** Library file names no longer wrap as the sidebar narrows: an ellipsis hides the beginning of a long path and keeps the file name visible. Hovering shows the full path.
- **Panel keys pressed during startup now work.** A number key pressed while the Viewer is still starting opens its panel once the window is ready, instead of being lost.

## Reading and drawing fixes from the core

- Nested symbols, graphics and fixed text are drawn in the order they are declared.
- Text and bounds follow deeply nested symbols as far as their graphics do.
- Spectre pins that differ only in case, such as `P` and `p`, stay separate.
- An included file that declares a supported RNL version is read even when the file including it has an unsupported version.
- RNL records inside scripts, embedded Verilog, `reliability` blocks, encrypted sections and similar regions are left uninterpreted, and the Problems panel says so.
- **New hints in Problems.** A file with non-ASCII characters in its host comments gets a hint that they have not been checked against a simulator.

Windows requires 64-bit Windows 10 or 11 and Microsoft Edge WebView2. The installers download WebView2 when it is missing. Linux requires x86_64, WebKitGTK 4.1 and a glibc version compatible with Ubuntu 22.04 or newer. On Linux systems without Chinese system fonts, Chinese text in the Netlist editor may show as boxes; installing a font such as `fonts-noto-cjk` fixes it. For macOS, build from [source](https://github.com/rich-netlist/rnl/tree/viewer-v0.3.0/apps/desktop).

The downloads are not code-signed. Windows may display a SmartScreen or unknown-publisher warning. Verify downloads against `SHA256SUMS.txt`.
