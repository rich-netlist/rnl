RNL Viewer 0.3.1 adds macOS packages and fixes Chinese text on Linux systems without Chinese fonts. The core is unchanged: this release goes with RNL core 0.3.0.

## macOS

- **Packages for Apple Silicon and Intel.** Use `RNL-Viewer-0.3.1-macos-arm64.dmg` on Macs with Apple Silicon and `RNL-Viewer-0.3.1-macos-x86_64.dmg` on Intel Macs. Both need macOS 13 or newer.
- **Installing.** Open the disk image, drag RNL Viewer to Applications, then eject it. To uninstall, quit the app and move it to the Trash. The settings are in `~/Library/Application Support/io.github.rich-netlist.viewer/settings.json`; delete that folder too if you want.
- **The app has an ad-hoc signature only**, with no Developer ID and no Apple notarization. If macOS blocks the first start of a download you trust:
  - choose Open Anyway in System Settings > Privacy & Security; or
  - run `xattr -dr com.apple.quarantine "/Applications/RNL Viewer.app"`.
- **Opening files from Finder.** Open With offers RNL Viewer for the netlist and package extensions it reads, and Get Info can make it the default app. A file opened while the Viewer is still starting is shown once the window is ready.
- **Menus and keys follow macOS.**
  - About and Quit are in the application menu.
  - Shortcuts use Cmd.
  - Cmd+Q quits, and still asks about unsaved edits.
  - In the editor, Control+Q keeps its text-editing meaning.
- **Tested on macOS 15.** The packages were installed from the actual disk images on Apple Silicon and on Intel and drew a sample circuit. macOS 13 and 14 were not tested on real machines, and neither was dragging a file from Finder into the window.

## Chinese text on Linux

- **The interface no longer shows boxes for Chinese text** on Linux systems without Chinese fonts. The editor, panels, symbol details, dialogs and the web viewer's menus now fall back to the Noto Sans SC fonts the Viewer already ships, for the characters the system fonts lack. Latin and monospaced text keep the system fonts, and the drawings are unchanged.
- **Some parts still need a system font.** The native GTK menus, native tooltips and system file dialogs do not use the Viewer's fonts. If Chinese shows as boxes there, install a Chinese font such as `fonts-noto-cjk` (`sudo apt install fonts-noto-cjk`) and restart the Viewer.
- **The web viewer loads more font data for Chinese text.** On systems without Chinese fonts, Chinese text now loads the font slices it needs, about 1.4 MB for a file with Chinese comments, and only once.

Windows requires 64-bit Windows 10 or 11 and Microsoft Edge WebView2. The installers download WebView2 when it is missing. Linux requires x86_64, WebKitGTK 4.1 and a glibc version compatible with Ubuntu 22.04 or newer.

The downloads are not code-signed with a publisher certificate. Windows may display a SmartScreen or unknown-publisher warning, and macOS asks as described above. Verify downloads against `SHA256SUMS.txt`, for example with `shasum -a 256` on macOS.

RNL Viewer is released under the MIT License. Its embedded Noto Sans SC Regular and Bold fonts and font metrics are released under the SIL Open Font License 1.1. The installers include both licences in `LICENSE.txt`, and Help > About identifies the fonts.
