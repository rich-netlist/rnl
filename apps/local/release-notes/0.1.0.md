RNL Viewer, local 0.1.0: the web viewer served on this computer by one static program, and shown by a browser, for older enterprise Linux (CentOS 7 / RHEL 8 / RHEL 9) and any Linux x86_64 of kernel 3.2 or newer, where the desktop viewer's libraries (WebKitGTK 4.1) are not to be had. It is a release of its own: it is not the desktop viewer (`viewer-v*`), whose AppImage and Debian package are as they were, and it is not the core's.

## Files

- `rnl-viewer-local-0.1.0-linux-x86_64.tar.gz`: the program (static: no library to find, no root, no network), its README and licenses, and `get-firefox.sh`, which puts Mozilla's official Firefox ESR beside it for a computer whose own browser is older than the page needs (Firefox 115 ESR or newer, Chrome, Chromium or Edge 89 or newer, Safari 15 or newer).
- `rnl-viewer-local-0.1.0-linux-x86_64-with-firefox.tar.gz`: the same with Mozilla's official Firefox ESR in the folder `firefox`, unmodified, where the program looks first. The program starts it in a profile of its own for each run, and never touches the user's own Firefox or its profile. Firefox is Mozilla's software under its own licenses (`firefox/`, `FIREFOX-NOTICE.txt`).
- `SHA256SUMS.txt`.

## Use

```
tar -xzf rnl-viewer-local-0.1.0-linux-x86_64-with-firefox.tar.gz
cd rnl-viewer-local-0.1.0-linux-x86_64-with-firefox
./rnl-viewer-local netlist.sp
```

Over `ssh` the browser may be on another computer: `./rnl-viewer-local --no-browser --port 8765 netlist.sp` on the server, `ssh -L 8765:127.0.0.1:8765 server` on the computer with the browser, and the address the program prints, which works once, in that browser. See the README for the options, what the program keeps of the desktop viewer and what it does not, and how it is kept safe on a computer that other users share.

## What it is

The web viewer, with the files of the computer the program runs on behind it: a file chooser that lists them, Save and Save As that write where the file was read from (in the encoding it had, whole or not at all, asking before a file that changed on disk or a name that is taken is replaced), a note when a file changes on disk, the settings in a file of the user's own, and Solve, which runs in the program on the machine's cores. The core runs in the browser as WebAssembly, so a big design is slower than in the desktop viewer and bounded by the browser's memory.

The program listens on `127.0.0.1` only, with a one-time address that is never on a command line and a key that the page sends with every request; see the README's Security.
