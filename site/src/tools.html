第一版 RNL 工具链 0.1 带两个查看器：网页版不用安装，打开就能用；桌面版给 Windows 10 和 11。它们读带 RNL 记录的网表，画成原理图，也能改网表的文本，应用后重画。网页版保存时下载文件；桌面版把文件写回原处，还能求解，结果作为预览显示，不写进文件。 The first RNL toolkit, 0.1, comes with two viewers: the web viewer, with nothing to install, and the desktop viewer for Windows 10 and 11. They read netlists with RNL records and draw them as schematics, and they edit the netlist’s text and draw it again when you apply the changes. The web viewer saves by downloading the file; the desktop viewer writes it back where it was read, and it also solves, showing the result as a preview that writes nothing into the files.

01 · 查看器01 · Viewers

打开网表，看到原理图，保存了才写。Open a netlist, see the schematic. Nothing is written until you save.

查看器打开一份带 RNL 记录的 SPICE 或 Spectre 网表，连同它 include 的文件，画出电路的每一层，旁边是网表文本、问题列表和层次结构。剪贴板里的网表文本也能直接打开：File › Load from Clipboard 先显示要打开的内容，确认后再打开。 A viewer opens a SPICE or Spectre netlist with RNL records, with the files it includes, draws each level of the circuit, and shows the netlist text, the problems and the hierarchy beside it. A netlist’s text in the clipboard opens too: File › Load from Clipboard shows the text first, and opens it when you confirm.

画出每一层Draws every level

顶层和每个子电路各是一张图，一次显示一层；拖动平移，滚轮缩放。双击子电路实例进入它的图，退格键回到上一层。 The top level and each subcircuit are drawings of their own, shown one at a time; drag to move, scroll to zoom. Double-click a subcircuit instance to open its drawing; Backspace goes back up.

网表文本The netlist text

网表和它 include 的文件分标签页显示，RNL 记录和网表语句都有高亮；没有生效的语句带底色。画子电路时，它的定义之外的文本变暗；进入子电路，文本就滚到它的定义开头。 The netlist and the files it includes, in tabs, with the RNL records and the netlist’s statements highlighted; statements that do not take effect have a soft background. While a subcircuit is drawn, the text outside its definition is dimmed, and entering it brings the start of its definition into view.

问题列表Problems

错误、警告和提示列在文本下方，点一条就跳到它所在的行；有问题的行号也会着色。 Errors, warnings and hints are listed below the text; click one to see its line. The line numbers of those lines are coloured too.

层次结构Hierarchy

从顶层展开的实例树，下面是所有子电路的索引，按首字母分组，可以搜索；点一个就打开它的图。 The tree of instances under the top level, and below it every subcircuit by name, grouped by initial, with a search box; pick one to open its drawing.

图和文本联动Drawing and text, linked

在图上点一个实例或一根导线，文本里会标出它的语句和每一处引用；反过来点文本，图上也会选中它。 Click an instance or a wire in the drawing, and the text marks its statement and every place that names it; click the text, and the drawing selects it.

没画出来的对象Objects not drawn

没写位置的对象画不出来，侧栏的 Not drawn 视图把它们列出来：每个都带着符号和各端子上的网络，可以按名字搜索；点一个，网表里就显示它的语句。状态栏说明这一层还缺什么，点它也会打开这个视图。 Objects without a position are not drawn, and the Not drawn view of the side panel lists them, each with its symbol and the nets at its terminals, searchable by name; pick one to see its statement in the netlist. The status bar says what the level lacks, and a click on it opens the view.

改文本，应用，保存Edit, apply, save

两个查看器都能改网表的文本。改了不会自己生效：应用了才重画，保存了才写文件，也不会自己求解。 Both viewers edit the netlist’s text. A change does nothing by itself: it is drawn when you apply it and written when you save it, and nothing solves by itself.

改文本Edit the text

Edit › Edit Text（Ctrl+E）把网表换成文本框，每个文件一个标签页，带行号。改过、还没保存的文件，标签上有一个点；还没应用的修改，文本上方会注明。 Edit › Edit Text (Ctrl+E) turns the netlist into a text box per file, each in its tab, with line numbers. A file with changes not saved has a dot on its tab, and the bar above the text says when changes are not applied yet.

应用Apply

Edit › Apply Changes（Ctrl+Enter）按改过的文本重新构建网表、重画，问题列表和层次结构也跟着更新；层级、视图和选择保持不变。构建失败时修改还在，查看器会说明原因。 Edit › Apply Changes (Ctrl+Enter) builds the netlist again from the edited text and draws it, with the problems and the hierarchy made again, keeping the level, the view and the selection. If the build fails, the changes stay and the viewer says why.

保存Save

File › Save（Ctrl+S）：桌面版把改过的文件写回原处，编码和换行照旧，别的文件不动；网页版写不了它读进来的文件，保存就是下载当前显示的文件。有没保存的修改时，打开别的文件、重新读取或关闭窗口之前会先问。 File › Save (Ctrl+S): the desktop viewer writes the edited files back where they were read, each in its encoding and with its line ends, and no other file; the web viewer cannot write a file it read, so Save downloads the file shown. With changes not saved, opening another file, reading it again or closing asks first.

两个查看器画出的图相同：同一个 Rust 核心决定每条线、每段文字放在哪里，在桌面上直接运行，在浏览器里编译成 WebAssembly 运行，文字都用它随附的字体排。 Both viewers draw the same schematic: one Rust core decides where every line and every piece of text goes, natively on the desktop and as WebAssembly in the browser, and lays out text in the fonts it ships.

02 · 网页版02 · Web viewer

网页版：不用安装，打开就能用。The web viewer: nothing to install.

网页版是一个静态网页，RNL 核心编译成 WebAssembly，在页面里运行。它能打开电脑上的文件或整个文件夹，也能打开网上的网表；把文件拖到页面上也行。 The web viewer is a static web page, with the RNL core compiled to WebAssembly running inside it. It opens files or a whole folder from your computer, or a netlist on the web; files dropped on the page open too.

打开网页版查看器Open the web viewerrich-netlist.github.io/rnl/viewer/

试试这几个例子Try these samples

例子来自 RNL 的一致性测试语料，和网页版一起发布。点一个，查看器就会打开它。 The samples come from RNL’s conformance corpus and are published with the web viewer. Click one and the viewer opens it.

  1. 04层次Hierarchy两级缓冲器：每个子电路一张图，在上一层画成方块符号，另有一个 include 进来的文件。A two-stage buffer: a drawing for each subcircuit, drawn as a block symbol one level up, and a file it includes.
  2. 15中文Chinese五管运放，RNL 用中文代称包 rnl-zh 写成，图上的标注也是中文。A five-transistor OTA written with the Chinese alias package rnl-zh, with Chinese labels in the drawing.
  3. 17线型Line styles每种线型画在每种图形上：虚线、点线、粗线和双线，画在矩形、圆、椭圆、圆弧和曲线上，也画在导线上。Every line style on every kind of shape: dashed, dotted, bold and double lines on rectangles, circles, ellipses, arcs and curves, and on a wire.

文件只在浏览器里Your files stay in the browser

从电脑上打开的文件只在页面里读取，不会上传到任何地方：这个网站只有静态文件，没有接收文件的服务器。 Files you open from your computer are read in the page and uploaded nowhere: the site is only static files, with no server to receive them.

从网址打开Open a URL

File › Open URL 从别的网站读取网表，它 include 的文件也从同一处读取。那个网站要允许跨源读取（CORS）；GitHub 的 raw 文件链接是允许的。 File › Open URL reads a netlist from another web server, and the files it includes from the same place. That server has to allow cross-origin reads (CORS), as GitHub’s raw file links do.

浏览器Browsers

Chrome 和 Edge 109 及以后的版本，Safari 16 及以后，Firefox 114 及以后（从这一版起支持 module Worker）。 Chrome and Edge 109 or later, Safari 16 or later, and Firefox 114 or later, the first with module Workers.

网页版也能改文本、应用后重画，见上面。网页写不了它读进来的文件，所以 File › Save 是下载：下载当前显示的文件，换行照旧，编码是 UTF-8。求解只有桌面版有，网页版没有 Solve 菜单。 The web viewer edits the text and draws it again when the changes are applied, as above. A page cannot write the files it read, so File › Save is a download: of the file shown, with the line ends it had, in UTF-8. Only the desktop viewer solves; the web viewer has no Solve menu.

网址里也可以带上要打开的网表，方便把链接发给别人：viewer/?url=https://raw.githubusercontent.com/…/04-hierarchy.sp 打开 GitHub 上的一份网表，连同它 include 的文件。 The viewer’s address can name the netlist to open, so a link can be shared: viewer/?url=https://raw.githubusercontent.com/…/04-hierarchy.sp opens a netlist on GitHub with the file it includes.

这里的网页版按 main 分支的最新提交构建，Help › About 显示它的版本和提交；Help › Desktop Viewer 回到这一页。 The web viewer here is built from the newest commit of the main branch; Help › About names its version and commit, and Help › Desktop Viewer leads back to this page.

03 · 桌面版03 · Desktop viewer

桌面版：Windows 10 和 11。The desktop viewer for Windows 10 and 11.

桌面版 RNL Viewer 按路径读写磁盘上的文件：网表 include 的文件放在哪里都能找到，文件改了按 F5 重新读取，改过的文本保存时写回原处，File › Save As 把网表另存为新文件。窗口里的页面和网页版相同，另外多一个 Solve 菜单，能求解。 The desktop RNL Viewer reads and writes files on disk by their paths: the files a netlist includes are found wherever they are, F5 reads a changed file again, edited text is saved back where it was read, and File › Save As saves the netlist under a new name. Its window shows the same page as the web viewer, with a Solve menu besides, which solves.

已发布的 0.1.0 版还只能看图：编辑、保存和求解是在它之后加进来的，下一个版本会带上。现在就要用，可以从源代码构建；只是改文本的话，网页版已经能用。 The released 0.1.0 only reads: editing, saving and solving came after it, and the next release brings them. To use them now, build the viewer from the source; for editing alone, the web viewer has it already.

求解，先作为预览Solving, as a preview

桌面版的 Solve 菜单用 rnl solve 的求解器排出没写位置的对象。结果只在窗口里显示，文件不变。 The desktop viewer’s Solve menu places the objects without a position with the solver of rnl solve. The result is shown in the window only, and the files stay as they are.

求解预览A solved preview

Solve › Solve（F9）照 rnl solve 的做法求解当前的网表，连同它 include 的文件，用的是已经应用的文本。求解在后台进行，窗口照常能用；状态栏显示正在解哪一层，可以取消。图上方注明这是预览、文件没有改动，侧栏的 Solve 视图列出求解报告，点一行就显示它在网表里的位置。Solve › Close Preview 回到文件本来的样子。 Solve › Solve (F9) solves the netlist shown, with the files it includes, as rnl solve does, from the text applied. It runs in the background, so the window stays usable, and the status bar shows the level being solved, with a Cancel button. The bar above the drawing says that this is a preview and the files are unchanged, and the Solve view of the side panel has the solve’s report, each line shown in the netlist when clicked. Solve › Close Preview shows the file as written.

另存求解副本Save a solved copy

Solve › Save Solved Copy As（Ctrl+Shift+S）把求解结果另存到你选的地方：网表不 include 别的文件时存成一个文件，默认名是 名字-solved.扩展名；否则存成一个文件夹，放求解后的文件和其余读到的文件，和 rnl solve -o DIR 写的一样。会覆盖任何一个读进来的文件时，查看器拒绝保存。 Solve › Save Solved Copy As (Ctrl+Shift+S) saves the result where you choose: one file, offered as NAME-solved.EXT, for a netlist that includes no other file; otherwise a folder with the files solved and the other files read, as rnl solve -o DIR writes them. A place that would replace any file that was read is refused.

求解设置The solver’s settings

Solve › Settings 设定求解器的选项：每层的时限、容差、网格、束宽、搜索和布线的工作量，以及给布局排序的目标：哪些开着，谁先谁后，同一级里各占多少权重。约束的优先级（low、normal、high）写在网表里，不在这里设。Restore Defaults 恢复求解器的默认值；设定下次启动还在。 Solve › Settings sets the solver’s options: the time limit of each level, the tolerance, the grid, the beam, the work of the search and the router, and the objectives that rank the placements: which are on, which counts first, and the weights of those that share a level. The priority of a constraint (low, normal, high) is written in the netlist, not set here. Restore Defaults brings back the solver’s defaults, and the settings stay for the next start.

04 · 工具链04 · Toolchain

RNL 工具链：读、解、画、改。The RNL toolchain: read, solve, draw, edit.

工具链把“读懂 RNL”和“把意图变成坐标”分成独立模块：没有求解器也能看图，需要时再求解。已经有的有：运行库、宿主适配器、渲染器和命令行，上面的两个查看器，还有求解器的第一版，在 rnl solve 和桌面版查看器里。选一条路径看数据怎么流动，点一个模块看它做什么。 The toolchain keeps “understanding RNL” and “turning intent into coordinates” in separate modules: you can view a drawing without a solver and solve only when needed. What exists today: the runtime, the host adapters, the renderer and the command line, the two viewers above, and a first version of the solver, in rnl solve and the desktop viewer. Pick a path to see how data flows; click a module to see what it does.
