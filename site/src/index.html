01 · 是什么01 · What

网表定义电路，RNL 描述怎样理解和呈现它。 The netlist defines the circuit. RNL describes how to understand and present it.

Rich Netlist（RNL）不是一种新的网表格式。它是写在现有网表注释里的一层描述：这些器件构成什么结构，设计者希望怎么摆，图上怎么画。 Rich Netlist (RNL) is not a new netlist format. It is a layer of description written in the comments of existing netlists: which structures the devices form, how the designer wants them placed, and how the drawing should look.

原生网表定义电路；Rich Netlist 描述如何理解和呈现这个电路。语义描述可以独立于几何存在，几何可以逐步细化，但两者都不能重新定义电路。 The native netlist defines the circuit; Rich Netlist describes how to understand and present that circuit. Semantic description can exist without geometry, and geometry can be refined step by step, but neither may redefine the circuit.

藏在注释里Hidden in comments

写在宿主网表的合法注释里，比如 SPICE 的 * @RNL {…}。仿真器把它当普通注释，不需要先剥掉。 Written in the host netlist’s legal comments, such as SPICE’s * @RNL {…}. Simulators treat it as an ordinary comment; nothing has to be stripped first.

不改电路Leaves the circuit alone

只能引用网表里的器件、网络和端子，不能新建器件、连接或参数。图上的线交叉、重叠，都不算连接。 It can only reference the netlist’s devices, nets and terminals; it cannot add devices, connections or parameters. Lines that cross or overlap in the drawing are not connections.

粒度随意Any level of detail

可以只写一句“M1、M2 是差分对”，也可以写到每个坐标和拐点，两种写法能在同一个文件里混用。 Write just “M1 and M2 are a differential pair”, or go down to every coordinate and bend; both styles can be mixed in one file.

  • 规定唯一画法的格式A format that prescribes one drawing
  • 像素级的图片存档A pixel-level image archive

原理图和网表各自保存一份连接关系。改了一边，另一边就可能过期；图上看着连着的线，网表里未必连着。 The schematic and the netlist each keep their own copy of the connections. Change one and the other may go stale; a line that looks connected in the drawing may not be connected in the netlist.

用 RNLWith RNL

连接只由网表定义。RNL 只能引用器件和网络，不能增删器件或连接；图上两条线交叉、端点重合，都不会变成连接。画导线时也一样：只有共用同一个点或端子的线才接在一起。 Connectivity is defined only by the netlist. RNL can only reference devices and nets, never add or remove devices or connections; two lines crossing, or endpoints landing on each other, never become a connection. Drawn wires work the same way: they join only where they share a point or a terminal.

电路只有一份真相，就是网表。The circuit has one source of truth: the netlist.

常见问题FAQ

加了 RNL 的网表，仿真器会报错吗？Will simulators complain about a netlist with RNL in it?

不会。RNL 只写在宿主网表的合法注释里，仿真器当普通注释跳过，不需要预处理。具体用哪个标记在各家仿真器里都安全，还在调研和验证。 No. RNL is written only in the host netlist’s legal comments, and simulators skip it like any other comment, with no preprocessing. Which exact marker is safe in every vendor’s simulator is still being researched and verified.

RNL 会改我的电路吗？Will RNL change my circuit?

不会。器件、参数和连接只由网表定义，RNL 只能引用它们。图上的线交叉、重叠，都不会产生连接；只改 RNL 时，网表正文原样保留。 No. Devices, parameters and connections are defined only by the netlist; RNL can only reference them. Lines that cross or overlap in the drawing never create connections, and when only RNL changes, the netlist body is kept as is.

一定要写坐标吗？Do I have to write coordinates?

不用。只写“M1、M2 是差分对，关于中轴对称”也是合法、有用的描述；坐标可以交给求解器，也可以以后逐步补上。 No. “M1 and M2 are a differential pair, symmetric about the center line” on its own is a valid and useful description; coordinates can be left to the solver or added later, bit by bit.

同一份 RNL，不同工具画出来一样吗？Will different tools draw the same RNL the same way?

写了精确几何的部分会一致；只写了意图的部分，不同求解器可以给出不同、但都满足意图的画法。RNL 不承诺像素级一致。 Parts with exact geometry will match. For parts that state only intent, different solvers may produce different drawings that all satisfy it. RNL does not promise pixel-identical output.

和 Virtuoso、KiCad 的原理图文件有什么不同？How is this different from Virtuoso or KiCad schematic files?

那些是各个工具自己的图形格式，和网表分开保存。RNL 附着在网表上，任何支持它的工具都能读；查看器也不自带元件库，符号本身就用 RNL 定义。 Those are each tool’s own graphical formats, stored apart from the netlist. RNL is attached to the netlist, and any tool that supports it can read it; viewers ship no component library either, because symbols are themselves defined in RNL.

为什么常提到 AI？Why does AI come up so often?

大模型擅长读写网表这样的文本。RNL 让“画法”也变成文本，模型能直接写出、局部修改。第一轮试写里，11 个模型照着参考写了 264 次，大多数写出了能用的 RNL。语句之间可以夹自由文本方便人读，但自由文本不改变机器读到的含义。 Language models are good at reading and writing text such as netlists. RNL makes the drawing text too, so a model can write it directly and edit it in place. In the first writing trial, 11 models wrote 264 runs from a reference, and most produced usable RNL. Free text between statements helps people read, but it never changes what machines understand.

可以用中文写 RNL 吗？Can RNL be written in Chinese?

可以。关键字和标准包里的名字都有中文代称，在文件头段记录里写 @USE-ALIASES(name="rnl-zh", version="0.3") 就能用，比如 #M1 @位于(10, 20)。代称只是另一种拼写：中英文写法可以混用，机器读到的完全相同；头段记录本身总按标准写法读。 Yes. Keywords and the names in the standard package have Chinese aliases; write @USE-ALIASES(name="rnl-zh", version="0.3") in the file’s header record and use them, as in #M1 @位于(10, 20). An alias is only another spelling: the two can be mixed, and machines read exactly the same thing; the header record itself is always read in standard spelling.

现在能用吗？Can I use it now?

看图和改文本可以：第一版工具链 0.1 的查看器能在浏览器里或 Windows 上打开带 RNL 的网表，画出写了坐标的部分，也能改文本、应用后重画。自动排版刚起步：求解器有了第一版，rnl solve 和桌面版查看器能用它排出只写了意图、没写坐标的部分，桌面版先作为预览显示。网页版还不能求解，这些部分它画不出来，只在 Not drawn 视图里列出。拖动器件的编辑器还没有。 For looking at drawings and editing the text, yes: the viewers of the first toolkit, 0.1, open a netlist with RNL in the browser or on Windows, draw the parts that have coordinates, and edit the text and draw it again. Laying out has just begun: the solver has a first version, with which rnl solve and the desktop viewer place the parts that give intent without coordinates, the desktop viewer as a preview. The web viewer does not solve yet, so it does not draw those parts and lists them in its Not drawn view. There is no editor for dragging devices yet.
