02 · 安装02 · Install

解压到 agent 存放 skill 的目录，得到 rnl/SKILL.md。Unpack it where your agent keeps skills. You get rnl/SKILL.md.

skill 就是文件夹 rnl/。Claude Code 把个人的 skill 放在 ~/.claude/skills/（所有项目都能用），项目里的放在 .claude/skills/；别的 agent 有它自己的目录，照它的说明放。下面两组命令把 zip 解压到 Claude Code 的个人目录。 The skill is the folder rnl/. Claude Code keeps personal skills in ~/.claude/skills/, where every project sees them, and a project’s own in .claude/skills/; other agents have a directory of their own, as their documentation says. The commands below unpack the zip into Claude Code’s personal directory.

macOS · Linux · Git Bash

mkdir -p ~/.claude/skills
curl -fL https://rich-netlist.github.io/rnl/skill/rnl-skill.zip -o /tmp/rnl-skill.zip
unzip -o /tmp/rnl-skill.zip -d ~/.claude/skills

Windows PowerShell

New-Item -ItemType Directory -Force "$HOME\.claude\skills" | Out-Null
Invoke-WebRequest https://rich-netlist.github.io/rnl/skill/rnl-skill.zip -OutFile "$env:TEMP\rnl-skill.zip"
Expand-Archive -Force "$env:TEMP\rnl-skill.zip" "$HOME\.claude\skills"

手动下载By hand

rnl-skill.zip 里是文件夹 rnl/ 和它的全部文件。解压后把 rnl/ 放进你的 agent 存放 skill 的目录。zip 和每个文件的 SHA-256 在 SHA256SUMS.txt，每个文件的大小和地址在 manifest.json。 rnl-skill.zip holds the folder rnl/ with all its files. Unpack it and put rnl/ where your agent keeps skills. The SHA-256 of the zip and of each file is in SHA256SUMS.txt, and the size and address of each file in manifest.json.

不安装，直接读Without installing

不能解压或写文件的 agent，直接读纯文本就行：先读 SKILL.md，它指向 references/ 下的文件。所有文件都在 skill/rnl/ 下，列在下面。 An agent that cannot unpack or write files reads the plain text as it is: SKILL.md first, which points to the files under references/. Every file is under skill/rnl/, listed below.

从仓库取From the repository

skill 的源文件在仓库的 skills/rnl/：克隆仓库，把那个文件夹复制过去，也一样。这里的 zip 总是照 main 的最新内容生成。 The skill’s source is skills/rnl/ in the repository: clone it and copy that folder, which comes to the same. The zip here is always built from the newest main.

04 · 检查和绘制04 · Check and draw

写完就检查，用能跑的第一个工具。Check what you write. Use the first tool you can run.

四个工具用的是同一个核心，读文件的结果相同。能自己运行的有前两个；后两个是给人用的。细节和命令都在 references/tools.md。 The four tools are one core, so they read a file the same way. An agent can run the first two itself; the other two are for a person. The details and the commands are in references/tools.md.

rnl

下载最新核心发布里 Windows、Linux 或 macOS 的压缩包，也可以从源码构建（Rust 1.85 或更新）：cargo build --release -p rnl-cli。rnl check FILE 打印诊断，有错误时退出码为 1；rnl render FILE -o DIR 为每一层写 SVG。最完整，也是 CI 用的那个。 Download the archive for Windows, Linux or macOS from the latest core release, or build it from source (Rust 1.85 or later): cargo build --release -p rnl-cli. rnl check FILE prints the diagnostics and exits 1 on errors; rnl render FILE -o DIR writes an SVG for each level. The most complete, and the one the CI uses.

npm

npm i @rich-netlist/runtime（Node 18 或更新）：同一个核心编译成 WebAssembly，给出诊断和每层的 SVG。版本号和 rnl 命令相同，随核心一起发布。 npm i @rich-netlist/runtime (Node 18 or later): the same core as WebAssembly, giving the diagnostics and an SVG for each level. It has the version of the rnl command and is released with the core.

网页版Web viewer

Open a file, see the drawing and the problems; nothing is uploaded. An agent that cannot drive a browser asks the person to open the file there.

Windows 10、11 和 Linux x86_64：下载在工具页。 Windows 10 and 11, and Linux x86_64: the download is on the page of the tools.
