RICH NETLIST · TRANSLATION

Translation status

English is the source of every text of RNL; every other language, Chinese included, is a translation that follows it.

This report was made from the list of what there is to translate when the site was built; every pull request gets the same one. To translate a language or bring one up to date, start from i18n/README.md.

How far each language is

The report is in English, as the texts it counts are. A missing translation shows the English; a stale one was made from an English text that has changed since.
