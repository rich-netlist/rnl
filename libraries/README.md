# libraries

External data libraries, separate from viewer code.

| Path | Content |
| --- | --- |
| [`standard/`](standard/README.md) | Drafts of the standard packages of RNL, a directory for each version: the standard package 0.2 with its sub-packages and symbols, and the Chinese alias package. |
| [`analog-canvas-extensions/`](analog-canvas-extensions/README.md) | The package `analog-canvas-extensions` 0.1: the symbols of Analog Canvas that the standard series 0.3 does not draw. Not standard; a file names it with USE-PACKAGE. |

See the [roadmap](../docs/roadmap.md) for planned work.
