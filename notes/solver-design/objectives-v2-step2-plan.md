## Shared contracts to freeze before parallel work

1. `GeometryFacts` contains normalized group-tree scopes, full `ProblemNet.pins` membership by physical `(object,pin)`, object host/point relationships, actual drawn pin exits, per-text object boxes and optional host. Marker predicate is pinless virtual + main object point/drawn terminal/wire (gate B02), without names. Relationship identity, never equal coordinates, grants object/text exemptions.
2. `RoutingGeometry` remains the source for scoring and writeback. Add an explicit event index keyed by point/physical-pin identity and network set. A zero-length pin-to-branch edge unifies the pin event for turn exemption, without unifying unrelated coincident pins. Authored wire identity is one output wire; generated identity follows the actual emitted pin/branch-to-pin/branch wire. No segment-local short/body double counting.
3. Canonical crossing segments merge only unbranched collinear subdivisions within the same wire/event topology. Crossings are strict interior/interior with no shared event at that coordinate; same-network crossings count, and a connection elsewhere does not exempt a crossing here. Turn degrees3/4 and explicit physical-pin events are exempt. Intermediate authored terminal points remain pin events.
4. C returns `TermValue { raw: Q, estimated: bool, inactive: bool, diagnostics, symmetry_axis }`. Report raw/weight/weighted/total/tolerance remain exact rational strings. Label boxes remain renderer-float then outward0.01-quantized approximations and must be flagged as such.
5. Symmetry needs a solve-level session, not an independently reset budget for every candidate. C exposes exact one-group measurement with deterministic step counter and cache key over original origins/pin coordinates; A preflights all placed candidates in a level. If any group exceeds the cap, recompute that term for every candidate using only the two group-envelope midlines. Never leave an uncomputed value at0 or compare full/reduced axes in one batch. Cache is invalidated by geometry/config scope changes; report fallback consistently. Root-group handling is based on normalized tree nodes once, with child proxy origin-bounds centers.
6. Scoring stages distinguish search sketch, placed candidate, and routed candidate. Symmetry is skipped on a search sketch, computed on placed candidates before route-beam ranking, and reused after routing. Nonrouting exact terms must not be marked estimated solely because ROUTE has not run. `pin_wire_alignment` pre-route L estimate and area lower bound differ from aspect estimate; report these truthfully.
7. B auto-mode evaluation receives an A-owned pure whole-configuration ranking callback over a proposed `RoutingGeometry`; it must not duplicate term logic. Enumerate horizontal-vertical, vertical-horizontal, then manhattan. For each placed candidate, before ROUTE, greedily choose each auto wire in problem.wires order on top of the previously chosen auto wires; use complete-config batch ranking of the three modes (ROUTE uses its pre-routing estimate), with listed mode order as the final tie. Then feed chosen author geometry to ROUTE and rank final candidates using real geometry. Preserve fixed author modes/cycles/zero lengths/buses/free points and write only auto changes through the normal13.1 writer. Manhattan half-grid bends stay exact.
8. The LP consumes terms in configured levels, with no level tolerance during LP optimum fixing. Skip nonlinear/count-only terms. `orientation_r0` and origin_distance are ordinary removable defaults; disabling them must not add an R0/L1 tie objective. origin_distance counts only unfixed symbol/free-point axes, excluding anchored text. Area uses the declared envelope-linear surrogate and is not claimed to exactly minimize real area.
