## 由代理决定并记录的细节

### 1. B02：无引脚标记也能合法挂在端子上

只读核对 `libraries/standard/0.3/rnl-std-basic.rnl:417`、`:421`、`:423`、`:440`–`:444`：NO_CONNECT、JUNCTION、CURRENT_ARROW、ARROW 的符号都没有 PIN；前三种合法主对象包含端子，ARROW 是点。标准 15.2 直接给出 CURRENT_ARROW 挂端子的例子。因此回复中“主对象不是端子”与“核对标准包标记都满足”不能同时成立。

**决定：**保留结构化识别，改成“虚拟符号无引脚，并且主对象为点、具有绘制引脚的端子或线”时视为标记；允许端子这一项。普通地、电源及端口符号有引脚，仍按普通虚拟符号处理，只豁免宿主对，与第三方碰撞仍计分。不得加定义名或符号名白名单，不得把所有 Position::At 都当标记。

理由：这是为覆盖标准包合法实例而修正方案作者的数据判据，符合其标记不计重叠的意图，不改变用户已经确定的目标或硬事实。补点上/端子上无引脚标记、有引脚地/电源与第三方、非挂接无引脚自有符号的区分测试即可，无需问用户。若实现发现其它结构，先按该显式类别判定，不因视觉上像箭头而扩豁免。

### 2. A07：组树、缓存和整层降级

旧 `algorithm-synthesis.md` 3.5 说重叠组拆块用于布局但按原组评分；新的 A07 明说“按组树拆开，每个节点算一次”。**以新回复为准**，symmetry 使用规范组树节点及父组代理，不同时累计旧原组和拆块，其他项按各自 scope 的契约。`scope=global` 可作为全体合格符号的一个合成组。偶数个尺寸的中位数采用中间两项的精确均值，轴相等按明确的 x→y、坐标序处理。

缓存应包含会影响值的对象/owner 身份、点坐标、组范围和该候选的 scale，而不能仅按裸坐标误复用。若任一候选耗尽完整轴集的预算，须重新统一该层所有候选为缩减轴集，不能把已算完整和后来缩减的分数混比，更不能将未算值当 0。具体计步单位、缓存结构和预估顺序由负责人决定并在测试中固定。

### 3. 必跑 wasm profile 与“不用 --release”

`bindings/runtime-wasm/build.mjs:41`–`:43` 固定调用 `cargo build --profile wasm`；`Cargo.toml:42`–`:46` 的 wasm profile 继承 release，`opt-level="s"`、LTO 开启、codegen-units=1。它确实做优化，不能把它描述成 debug 或轻量构建。

**决定：**保留交接明确指定的两条 build.mjs 命令及仓库专用 wasm profile；“不用 --release”落实为不额外进行原生 release 构建。专用 wasm 构建是必跑验收要求的窄范围例外，仍完全受本机资源规则约束：CARGO_BUILD_JOBS=4，全局只跑一个 cargo；启动前 cargo/rustc 隔 5 秒两次为空且空闲内存不少于 8GB；Node/Playwright 的间接构建也进入同一队列。不得为了消除表面冲突而跳过 wasm 验收或改 profile 后称与 CI 相同。出现内存压力先停止该构建并记录，再由验证负责人处理；本次未执行任何构建。

### 4. 普通实施选型

精确 TOML 库需实测词素/span 支持后选择；局部路由有限级倍率、去重状态、确定排序键、报告 JSON 字段、CLI 共享读取函数位置、候选展开与计步实现都可由负责代理决定。必须保证同输入/同有效配置确定、精确值不经 f64/JS Number 丢失，且把选择及理由写进决策记录。配置数值和预算拒绝非法范围，不能静默截断。无须再让用户选择库、类型名或缓存容器。
