# RNL core 0.1.4

These notes describe the current workspace version for build rehearsals. The first core
publication version and npm dist-tag still require the user's release decision; this file
does not authorize publishing 0.1.4. Rename and update it if a different version is chosen.

- The core has its own `core-vX.Y.Z` release line. One tag builds the CLI archives and
  `@rich-netlist/runtime` at the same version, independently of RNL Viewer and the standard.
- Download the CLI for Windows x64, Linux x86_64 (static musl), macOS Apple Silicon or Intel.
  Each archive includes the code, standard-package and font-metrics licences. Verify the
  archive against `SHA256SUMS.txt`; `rnl --version` reports its version and build commit.
- Windows statically links the C runtime; no VC++ runtime installation is required.
- Linux arm64 is not included in this initial matrix.

The executables have **no code signature**. Windows may show a SmartScreen warning.
On macOS, a browser download may need `xattr -d com.apple.quarantine rnl` after extraction
before the executable can run. Review the download's checksum first.
