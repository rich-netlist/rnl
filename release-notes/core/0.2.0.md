# RNL core 0.2.0

The first release of the RNL core on its own release line. The core reads SPICE and Spectre
netlists with RNL 0.3 records, checks them, draws them and solves their layout; the `rnl`
command and the npm package `@rich-netlist/runtime` are both built from it and share its
version. RNL Viewer and the language standard are released separately, under `viewer-v*`
and `spec-*`.

## What is new

- **Ready-to-run `rnl` executables** for Windows x64, Linux x86_64, macOS on Apple Silicon and
  macOS on Intel. Nothing needs installing: no Rust toolchain, and on Windows no VC++ runtime,
  since the C runtime is linked statically; the Linux executable is linked statically with
  musl and runs on any distribution. Each archive holds the executable and the licences of the
  code, the standard packages and the font metrics it embeds.
- **`rnl --version`** prints the core version and the commit it was built from.
- **Stable download links.** The archive names carry no version, and the core's releases are
  the repository's latest, so a link such as
  <https://github.com/rich-netlist/rnl/releases/latest/download/rnl-x86_64-pc-windows-msvc.zip>
  always gives the newest core.
- **The npm package takes the core's version.** `@rich-netlist/runtime` 0.2.0 is published under
  the dist-tag `latest`, so `npm i @rich-netlist/runtime` installs it. The earlier previews,
  0.1.0-preview.8 to 0.1.0-preview.15, stay available under their exact versions; `next` still
  points at preview.15.

## For users of the npm previews

The core in 0.2.0 is that of 0.1.0-preview.15, with `--version` added to the command line. As
in preview.15, the package no longer ships the file of `analog-canvas-extensions`: read it from
the [rnl-packages catalog](https://rich-netlist.github.io/rnl-packages/catalog.json), check its
SHA-256, and pass it to the core through `files` and `pool`.

## Files

| File | |
| --- | --- |
| `rnl-x86_64-pc-windows-msvc.zip` | Windows x64 |
| `rnl-x86_64-unknown-linux-musl.tar.gz` | Linux x86_64, statically linked |
| `rnl-aarch64-apple-darwin.tar.gz` | macOS on Apple Silicon |
| `rnl-x86_64-apple-darwin.tar.gz` | macOS on Intel |
| `SHA256SUMS.txt` | The SHA-256 sums of the archives: `sha256sum --check --ignore-missing SHA256SUMS.txt`, or `Get-FileHash` in PowerShell |

Linux on arm64 is not built yet; build the command from the source there.

## Not signed

The executables have no code signature. Windows may show a SmartScreen warning. On macOS, a file
downloaded with a browser may need `xattr -d com.apple.quarantine rnl` after it is extracted
before it runs. Check each download against `SHA256SUMS.txt` first.
